
#  CallCenter Hub: Plataforma de Gestión y Monitoreo de Atención

##  Descripción del Proyecto
CallCenter Hub es una aplicación web Frontend desarrollada en React orientada a la gestión, registro y control operativo de un centro de llamadas. La plataforma permite administrar el flujo de atención a clientes, el estatus de los agentes (disponible, en llamada, en pausa), el registro de tickets de soporte y la visualización de métricas de rendimiento en tiempo real. 

Este proyecto se enfoca en resolver necesidades reales de negocio: control de tiempos de espera, clasificación de incidencias y un historial persistente de interacciones conectado a una base de datos relacional (MySQL).

---

## ⚙️ Dinámica de Trabajo y Metodología (Enfoque Individual Ágil)
Para garantizar el éxito, la calidad del código y la organización de este proyecto individual, se aplicarán principios del marco de trabajo **Scrum** adaptados al desarrollo unipersonal:

* **Gestión de Tareas y Sprints:**
  * El desarrollo se dividirá en iteraciones o Sprints (por ejemplo, Sprint 1: Estructura y Vistas en React; Sprint 2: Lógica y Conexión de Datos; Sprint 3: Despliegue y Pruebas).
  * Se utilizará un tablero de tareas para priorizar requerimientos funcionales y no funcionales antes de programar.

* **Control de Versiones y Buenas Prácticas (Git Flow):**
  * Uso de control de versiones local y remoto mediante **Git y GitHub**.
  * Creación de commits descriptivos, limpios y orientados a la funcionalidad (ej. *"feat: implementación del módulo de registro de tickets"*).
  * Estructura modular del código en React para asegurar escalabilidad, mantenimiento y legibilidad.

## 🛠️ Tecnologías Previstas
* **Frontend:** React, HTML5, CSS3 / Tailwind CSS.
* **Gestión de Datos:** MySQL (para el almacenamiento persistente de agentes, clientes y registros).
* **Control de Versiones:** Git y GitHub.
* **Despliegue:** Vercel.
